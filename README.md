# Toontown Landwalker Archive By Luca
Most of these scripts have been forgotten to the passage of time, never to be remembered.

I initially modified (stolen) scripts I made (stole) back in 2018 (from PasteBin) to make a gift (a modified version of Toontown) for my cousin from France. All the way when I was a 13 year old with an obsession for Toontown!

Oh! The "Channel Picture" scripts were for my old channel. They should open an empty canvas with a blue mouse in it.

I hope someone can have as much fun as I did modifying these Toontown scripts.

## REQUIREMENTS
- Panda3D
- Python
- Lots of patience
- A dash of olive oil
- And a four leaved clover (for good luck)!

## Usage
Run ```play.py``` and input the name of the file you want to run (for example ```python play.py Estate.py```) and it opens by itself. **THE SCRIPT IS CASE-SENSITIVE**

### P.S.

There are some Maya 2016 (I think?) files along with the .bam files here. all made by me and my mom when we were trying to make the olaf head. I don't know if the fox head was made by me or if I also "borrowed" it.
